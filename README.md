# Ayan074-Automated-Long-Answer-Grading-using-QLoRA-Fine-Tuned-Qwen2.5-3B-Instruct
Automated Long-Answer Grading System using QLoRA fine-tuned Qwen2.5-3B-Instruct. The system evaluates descriptive student answers against criterion-level rubrics, predicts individual criterion scores, and generates final scores using a lightweight, locally deployable LLM.
